01 · Plan

영상 기획

촬영을 시작하기 전, 누구에게 무엇을 보여줄지부터 정리합니다.

청중 이해하기
  • 타겟 고객을 식별하는 것이 가장 중요합니다.
  • 인구통계·관심사·그들이 사용하는 플랫폼을 먼저 고려하세요.
  • 실제로 볼 사람 한 명을 정해 놓는다고 생각하는 ‘페르소나’ 상정하기가 도움이 됩니다.
  • 전문 용어 사용은 자제하거나, 쉽게 풀어서 설명하세요.
동영상 스토리보드(콘티) 만들기

스토리보드를 사용해 영상을 미리 계획하면 아이디어를 정리하고 논리적인 흐름을 보장하는 데 도움이 됩니다.

  • 최종 결과물을 미리 시각화하고, 개선할 부분을 찾기 위해 장면·동작·대화의 개요를 작성해 봅니다.
  • 영상 업계에서는 이를 ‘콘티’라고 부릅니다.

02 · Shoot

촬영 노하우

장비, 화질 설정, 인물 촬영 팁, 화각과 카메라 무빙까지 — 촬영 전 알아야 할 실전 지식입니다.

촬영 액세서리
  • 삼각대 및 안정 장치 — 흔들리는 영상을 방지하고 안정적인 촬영을 보장합니다.
  • 외부 마이크 — 오디오 품질을 향상시키고 주변 소음을 줄여줍니다.
  • 조명 장비 — 적절한 조명을 위해 소프트박스, 링 라이트를 사용하세요.
속도와 방향이 주는 재미
  • 슬로우모션 / 슈퍼슬로우모션 — 아이폰은 촬영 화면 바로 아래에서 슬로 모션을 선택한 뒤 촬영합니다.
  • 하이퍼랩스 / 타임랩스 — 시간의 흐름을 빠르게 압축해서 보여줍니다.
  • 인터벌 촬영 — 일정한 간격으로 촬영해 타임랩스 효과를 만듭니다.
  • 역방향 재생 — 영상을 거꾸로 재생해 재미 요소를 더합니다.

가로 영상 기준 “1,080p”라고 하면 가로 1,920픽셀·세로 1,080픽셀 영상을 뜻합니다. 유튜브에서 톱니바퀴(설정)를 눌러 화질을 선택할 때 보이는 표기도 같은 방식입니다.

최종 결과물은 FHD(1080p)로 만들더라도, 편집에는 여유가 있도록 더 높은 화질(UHD 30 정도)로 촬영하는 것이 무난합니다. 촬영 전에는 항상 화질 설정부터 확인하세요.
촬영 시 꼭 체크할 것
  • 포맷 설정 / 초점 / 밝기 / 구도
  • 자세 — 사진과 영상의 흔들림을 직접 제어
  • 움직이며 촬영할 때는 슈퍼스테디(손떨림 방지) 활성화
  • 속도 조절 — 슬로우모션, 하이퍼랩스, 타임랩스
  • 짧은 영상을 여러 개 많이 촬영해 두기
연습해 볼 것: 5초 정지영상 찍어보기 · 앵글 바꾸어 찍어보기 · 움직이며 찍어보기. 좋은 영상의 조건은 결국 “계속 볼 수 있는 영상 + 안정적인 영상 + 정확한 초점과 밝기 + 좋은 오디오(목소리·BGM·효과음)”입니다.
전신 인물사진 늘씬하게 찍는 법
  • 얼굴은 화면 중앙 부근에, 발 아래 공간은 조금 남기고 촬영합니다.
  • 스마트폰을 아래로 살짝 기울여, 아랫부분을 밀어내듯 촬영합니다.
초점거리와 화각의 활용

  • 광각 / 표준 / 망원을 상황에 맞게 적절히 활용하세요.

03 · Grammar

쇼트 & 편집의 기본 문법

영상 언어의 기본 단위를 알면 촬영 계획과 편집이 훨씬 쉬워집니다.

쇼트(Shot)의 크기 7종
롱샷 LS
인물과 배경을 넓게 담아 상황·공간을 보여줌
풀샷 FS
머리부터 발끝까지 인물 전신이 화면에 들어옴
니샷 Knee Shot
무릎 위부터 보이는, 풀샷보다 조금 다가간 샷
웨이스트샷 Waist Shot
허리 위부터 보이는 샷
바스트샷 Bust Shot
가슴 위부터, 인터뷰 등에 가장 흔히 쓰임
클로즈업샷 CU
얼굴 등 특정 부분을 크게 확대
오버숄더샷 OTS
한 사람의 어깨너머로 상대를 보여줌, 대화 장면에 자주 사용
영상 편집의 단위
  • 쇼트(Shot) — 촬영의 가장 기본이 되는 단위
  • 컷(Cut) — 쇼트에서 필요한 부분만 잘라낸 것
  • 씬(Scene) — 같은 장소·같은 시간에 벌어지는 하나의 사건
  • 시퀀스(Sequence) — 여러 씬이 모여 이루는 하나의 독립된 에피소드
  • 스토리(Story) — 시퀀스가 모여 완성되는 전체 이야기
필수 영상 편집 효과 한눈에 보기

컷편집 · 크롭 · 확대/축소 · 키프레임 · BGM · 효과음 · 나레이션 · 전환효과 · 자막

컷편집을 하는 이유 — 원치 않는 부분을 자르기 위해, 지루함을 방지하기 위해, 특정 구간에 효과를 넣을 편집점을 잡기 위해서입니다.

추가로 필요한 요소 — 썸네일, 오프닝, 엔딩, 스티커, 말자막.

04 · Edit

CapCut PC 실습 가이드

강의에서 실습한 순서 그대로 정리했습니다. 반드시 C드라이브에 캡컷 폴더를 만들고 편집을 시작하세요. 프로젝트는 완성된 영상이 아니라 “편집 중인 상태”이므로, 언제든 다시 불러와 이어서 작업할 수 있습니다.

실습 자료 다운로드

개미 할머니 영상폴더 열기 · Google Drive 정지된 영상파일 열기 · Google Drive 역방향 재생 예제파일 열기 · Google Drive
파일 가져오기 & 타임라인
  • 타임라인으로 옮겨야 실제 편집이 이루어집니다.
  • 레이어가 쌓이면 위에 있는 레이어만 화면에 보입니다.
  • 비율 설정 — 가급적 가로와 세로를 미리 구별해서 시작하세요.
  • 편집 메뉴는 클립이 선택되어야 나타납니다. 편집이 적용되는 곳은 재생 위치(playhead)가 아니라 흰색 박스로 선택된 클립입니다 — 항상 확인하세요.
기울기 보정 & 크롭, 밝기·색감 보정

기울어진 영상을 바로잡고 필요한 부분만 크롭합니다.

영상 밝기 및 색감 보정 — 동영상 옆 → 조정 → 기본 → 조정(온도, 색조, 채도)

얼굴 · 몸매 보정(Enhance)
  • 얼굴 슬림하게 — 기본 세 번째 옆 → 보정(Enhance) → 단독인물 또는 그룹 선택
  • 몸매 슬림하고 길쭉하게 — 기본 세 번째 옆 → 보정(Enhance) → 몸 선택
컷편집: 분할 · 삭제
  • 화면을 분할하고, 삭제할 클립을 선택한 뒤 DEL 키로 삭제합니다.
  • 스페이스바 — 영상을 멈추고 재생합니다.
  • 단축키 Q — 앞 부분 영상 삭제 / 단축키 W — 뒷 부분 영상 삭제
  • ‘자동으로 붙이기’ 옵션이 켜져 있어야 삭제 후 클립이 자동으로 붙습니다.
실습 포인트 — 클립 순서 바꾸기 · 트림 · 분할
가로 영상을 세로로 사용하기

동영상 → 기본 → 캔버스 옆 삼각형 클릭 → 색상·패턴 등을 선택하면 캔버스 색을 원하는 대로 바꿀 수 있습니다.

영상 편집의 꽃: 속도 조절
  • 동영상 옆 → 속도 → 표준(속도, 기간) / 곡선
  • 역방향 재생, 프리즈 — 타임라인 위쪽 버튼에서 적용
키프레임

시작점부터 종착점까지 효과를 서서히 적용합니다 — 패닝, 틸팅, 줌인, 줌아웃.

  • 한 번에 확대되는 것이 아니라 천천히 확대되는지 꼭 확인하세요.
  • 확대뿐 아니라 위치까지 이동시키고 싶다면 “변형” 옆에 있는 키프레임을 선택합니다.
화면 시작 & 장면 전환
  • 부드러운 화면 시작 — 편집 효과 > 동영상 효과 > 오프닝&클로징
  • 장면 전환 — 왼쪽 화면, 가져오기 옆 → 전환(트랜지션) → 아래에서 여러 종류 선택
오디오: 음향 개선 · BGM · 효과음 · 나레이션
  • 음향 개선 — 동영상 옆 → 오디오 → 기본(볼륨, 페이드 인/아웃) → 음성 변조기(음성필터, 음성유형)
  • 배경 음악(BGM) — 가져오기 옆 오디오 → 음악 → 기본(볼륨, 페이드 인/아웃)
  • 효과음 — 가져오기 옆 오디오 → 아래 음향 효과
  • 나레이션(후시녹음) — 동영상 중간에 있는 마이크 모양 아이콘
실습 포인트 — 후시녹음 · 나레이션 직접 녹음해보기
자막 (타이틀 · 말풍선 · AI 자동자막)
  • 타이틀 및 기본 자막 — 가져오기 옆 → 텍스트 → 텍스트 추가 또는 텍스트 템플릿
  • 자막 수정 — 우측 캡션에서 줄바꾸기/합치기, 캡션 옆 텍스트에서 글꼴·색상 변경, 텍스트 기본 옆 말풍선
  • AI 자동 자막 생성 — 가져오기 옆 → 캡션 → 아래 자동 캡션 → 한국어 → 생성
  • 자막 음성 변환 — 텍스트 옆 → 음성변환 (자막 클립이 선택되었는지 반드시 확인)
배경 변경 · 얼굴 모자이크(PRO)
  • 배경 변경(PRO) — 동영상 → 아래 배경제거 → 자동삭제(Pro), 또는 동영상 → 기본 → 아래 캔버스에서 색상·패턴 변경
  • 얼굴 모자이크 — 가져오기 옆 편집 효과 → 신체효과에서 “얼굴 모자이크” 찾기
템플릿 · 스톡 자료 활용
  • 템플릿 활용 — 가져오기 맨 우측에 있는 템플릿
  • 스톡 자료 활용 — 가져오기 → 아래 스톡자료 클릭
