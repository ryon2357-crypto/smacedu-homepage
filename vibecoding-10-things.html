1랜딩페이지·홈페이지

강의·상품 하나를 소개하고 신청까지 받는 한 장짜리 웹페이지.

만드는 것

  • 제목·핵심 혜택·커리큘럼·일정·가격·후기·신청 버튼을 갖춘 페이지
  • 스마트폰에서도 깨지지 않는 화면, 카카오톡에 링크를 보냈을 때 뜨는 미리보기 이미지(썸네일)

이렇게 시킨다

우리 강의 "OOO"의 랜딩페이지를 HTML 한 파일로 만들어줘. 구성은 ①한 줄 약속 ②이런 분께 추천 ③배우는 내용 5가지 ④일정과 가격 ⑤신청 버튼 순서. 모바일에서 먼저 예쁘게 보이게 하고, 글씨는 크게, 색은 따뜻한 베이지와 주황 계열로 해줘.

결과

시킨 지 몇 분 안에 브라우저에서 열리는 페이지가 나옵니다. "버튼 색을 바꿔줘", "가격 줄을 더 크게" 같은 말로 계속 고칩니다. 마음에 들면 호스팅에 올려 주소(URL)로 공개합니다.

이런 분께

강사, 소상공인, 공방·학원 운영자, 스마트스토어 판매자

실제 사례 · 코클 바이브코딩 실전반 1기 랜딩페이지와 카카오톡 공유 썸네일(smacedu.kr).

2수강생 전용 자료실

강의가 끝난 뒤 녹화본·자료·실습 파일을 한곳에 모아 주는 비공개 페이지.

만드는 것

  • 녹화 영상 + 구간별 타임코드(몇 분 몇 초부터 무슨 내용인지)
  • PPT·PDF 다운로드 버튼, 실습 파일 직접 다운로드
  • 클릭 한 번으로 복사되는 프롬프트 모음(지금 이 문서의 검은 상자처럼)
  • 검색 결과에 나오지 않도록 비공개 설정

이렇게 시킨다

강의 수강생용 자료실 페이지를 만들어줘. 위에는 녹화 영상 링크, 그 아래에 타임코드 5개(0:00 오프닝, 12:30 …), 강의 PPT 다운로드 버튼, 따라 해볼 프롬프트 10개는 각각 "복사" 버튼을 달아줘. 검색엔진에는 노출되지 않게 해줘.

결과

강의 후 "자료 어디 있어요?"라는 문의가 줄고, 구매자에게 링크 하나만 보내면 끝납니다.

이런 분께

온라인 강의 운영자, 클래스 판매자, 사내 교육 담당자

실제 사례 · 코덱스 특강 수강 자료실. 편집본 영상 타임코드 5개, 학습자료 PDF, 복사형 프롬프트 10개를 한 페이지에 담았습니다.

3신청서 + 접수 자동화

신청서를 받으면 시트에 쌓이고, 신청자에게 안내 메일이 알아서 나가는 흐름.

만드는 것

  • 구글폼(성함·이메일·연락처·선택 항목) → 구글 시트에 자동 저장
  • 신청이 들어오면 몇십 초 안에 신청자에게 안내 메일 자동 발송
  • 마감 시각이 지나면 자동 안내를 멈추는 규칙

이렇게 시킨다

구글 시트에 새 행이 추가되면 그 사람 이메일로 "신청 감사합니다. 줌 링크는 …" 메일이 자동으로 가게 Apps Script를 만들어줘. 같은 사람에게 두 번 가지 않게 "발송완료" 열에 표시하고, 강의 시작 2시간 뒤부터는 발송을 멈춰줘.

결과

밤에 신청이 들어와도 사람이 일어나서 답장하지 않아도 됩니다. 시트 한 장으로 접수 현황이 보입니다.

이런 분께

무료 특강으로 고객 명단을 모으는 모든 사업자

실제 사례 · 한가위 선물 신청 시 14초 안에 안내 메일 발송, 정해진 날짜에 자동 중지.

4나만의 운영 대시보드

엑셀·캘린더·메일에 흩어진 내 사업 현황을 한 화면에 모은 개인용 웹페이지.

만드는 것

  • 이번 달 강의 일정 캘린더, 입금 확인 현황, 미입금 목록
  • 상품별 접수 인원과 금액을 숫자 카드로 표시
  • 내 PC에서만 열리는 비공개 화면(외부 노출 없음)

이렇게 시킨다

내 매출 엑셀 파일(sales.xlsx)을 읽어서 상품별 접수 인원과 입금 합계를 카드 3개로 보여주는 웹 화면을 만들어줘. 입금이 확인되지 않은 건은 따로 "확인 필요"로 빼서 합계에 넣지 말아줘. 내 컴퓨터에서만 열리게 해줘.

결과

매번 엑셀을 열어 합계 내던 일이 "새로고침 한 번"으로 바뀝니다.

이런 분께

매출·재고·예약을 엑셀로 관리하는 소규모 사업자

실제 사례 · 접수관리 화면 상단에 8만원 바이브코딩 접수 카드를 추가. 입금이 매칭된 건만 집계하고 금액이 애매한 건은 "확인 필요"로 분리했습니다.

5개별 메일 대량 발송 도구

수십~수천 명에게 "받는 사람 이름이 각자 보이는" 메일을 보내고, 잘 갔는지 확인까지.

만드는 것

  • 명단 파일에서 이메일을 읽어 중복·오타 주소를 걸러 내는 기능
  • 예쁜 HTML 메일 본문(큰 버튼, 이미지 포함) 템플릿
  • 발송 결과 로그(성공/실패 건수)와 실패 주소 정리

이렇게 시킨다

emails.csv의 이메일 주소로 같은 내용의 HTML 메일을 한 명씩 따로 보내는 파이썬 스크립트를 만들어줘. 보내기 전에 중복과 형식이 틀린 주소를 빼고 몇 명인지 먼저 알려줘. 발송이 끝나면 성공·실패 건수를 로그 파일로 저장해줘. 먼저 나에게만 테스트로 1통 보내는 옵션도 넣어줘.

결과

"발송 전 점검 → 테스트 1통 → 본 발송 → 결과 확인"의 순서가 도구에 들어 있어서 실수가 줄어듭니다.

알아 두세요 · 스팸 규정과 수신 동의를 지켜야 하고, 로그의 "발송 완료"만 믿지 말고 보낸편지함에서 실제 발송을 한 번 더 확인하는 습관이 필요합니다.
실제 사례 · 후기 제출자 대상 선물 안내 메일을 개별 발송. 중복 주소를 정리한 뒤 발송 성공 85건, 실패 0건.

6수료증·증명서 자동 발급

이름과 번호만 넣으면 디자인된 PDF가 한 장씩 만들어지는 도구.

만드는 것

  • 수료증 디자인 틀에 이름·날짜·일련번호를 자동으로 채우는 기능
  • 명단 시트에서 여러 명분을 한 번에 PDF로 생성
  • 이미 발급한 사람과 번호가 겹치지 않게 막는 안전장치

이렇게 시킨다

수료증 템플릿 이미지(template.png) 위에 명단 시트의 이름, 수료일, 일련번호를 지정한 위치에 넣어서 이름별 PDF로 저장해줘. 같은 이름이나 같은 번호가 이미 있으면 만들지 말고 알려줘.

결과

수강생 30명이면 30장을 한 번에. 손으로 한 장씩 고치다 생기던 오타와 번호 중복이 없어집니다.

이런 분께

수료증·상장·참가증·회원증을 자주 만드는 강사와 단체

실제 사례 · 민간자격 14종 발급 파이프라인(명단 → 발급 → 관리대장 기록).

7반복 서류 자동 작성

매번 같은 정보를 손으로 옮겨 적던 신청서·계획서·확인서를 자동으로 채우는 도구.

만드는 것

  • 내 정보(이름·경력·소속)를 한 번만 저장해 두고, 양식에 맞춰 자동 입력
  • HWP·PDF·워드 등 제출용 파일로 바로 저장
  • 기관마다 달라지는 항목(일정·과목)만 말로 알려 주면 반영

이렇게 시킨다

첨부한 양식 파일의 빈칸을 아래 정보로 채워서 PDF로 저장해줘. 이름: …, 소속: …, 일정: 10/6, 10/7, 10/13, 과목: …. 채운 결과를 한 장으로 보여주고, 비어 있는 칸이 있으면 알려줘.

결과

서류 한 건에 30분 걸리던 일이 확인만 하면 되는 일로 바뀝니다.

이런 분께

관공서·기관에 서류를 자주 내는 강사, 프리랜서, 학부모·직장인 (결재·제출용 서류)

실제 사례 · 대학 출석인정원(외부 강연 3일, 5과목)을 양식에 맞춰 1쪽 PDF로 작성.

8나만의 AI 비서 챗봇

내 업무 자료를 알고 있어서 "오늘 뭐부터 할까?"에 답해 주는 채팅 화면.

만드는 것

  • 카카오톡처럼 대화하는 웹 화면(PC·스마트폰 모두 접속)
  • 일정·접수·미입금 같은 내 데이터를 읽어 와서 "지금 결정할 것"만 골라 알려 주는 규칙
  • 매일 아침 요약 보고를 메일로 보내는 기능

이렇게 시킨다

내 일정 파일과 접수 시트를 읽어서, 매일 아침 "오늘 해야 할 일 3가지"와 "마감이 임박한 것"만 요약해 주는 채팅 화면을 만들어줘. 정보를 나열하지 말고 내가 결정해야 할 것만 골라줘.

결과

"전부 보여 주는 도구"가 아니라 "골라 주는 비서"가 핵심입니다. 무엇을 알려 줄지의 기준을 말로 정해 주는 것이 바이브코딩의 진짜 실력입니다.

실제 사례 · 비서실장 '아라' 채팅 웹앱과 아침 브리핑 메일.

9자동 알림·반복 작업 봇

사람이 매일 하던 클릭·확인을 정해진 시간에 대신 해 주는 프로그램.

만드는 것

  • 새 공고·새 글이 올라오면 내 카카오톡·메일로 알림
  • 이웃 블로그·카페에 정해진 규칙으로 인사 댓글을 남기는 봇
  • 정해진 시각에 파일 정리·백업·보고서 생성

이렇게 시킨다

○○ 사이트의 공고 목록을 매일 오전 9시에 확인해서, 새로 올라온 공고 중 제목에 "강사"가 들어간 것만 골라 나에게 메일로 보내주는 프로그램을 만들어줘. 이미 보낸 공고는 다시 보내지 않게 기록해줘.

결과

내가 잠든 사이에도 일이 돌아갑니다. 단, 로그인이 만료되면 멈추기 때문에 "멈췄을 때 알려 주는 기능"까지 함께 시키는 것이 좋습니다.

알아 두세요 · 사이트의 이용약관과 자동 접속 허용 여부를 먼저 확인해야 하고, 개인정보를 모으는 용도로는 쓰면 안 됩니다.
실제 사례 · 카페·블로그 환영 댓글 봇, 강의 공고 수집, 카카오 '나에게 보내기' 알림.

10크롬 확장·미디어 자동화

"이런 기능이 있으면 좋겠다"를 내 브라우저와 내 작업 파일에 직접 붙이는 도구.

만드는 것

  • 화면 캡처 → 글자 인식(OCR) → 주석 달기까지 하는 크롬 확장
  • 강의 녹화 영상에서 자막 파일(SRT)을 자동으로 뽑는 프로그램
  • 줌 강의 녹화를 정해진 시각에 시작하는 자동화

이렇게 시킨다

영상 파일(lecture.mp4)의 음성을 글자로 바꿔서 자막 파일(.srt)로 저장하는 프로그램을 만들어줘. 한 줄은 최대 20자로 끊고, 끝나면 몇 개의 자막이 만들어졌는지 알려줘.

결과

시중 도구를 사서 쓰던 것을 내 입맛대로 만들어 쓰게 됩니다. 영상을 만들거나 강의를 올리는 분께 특히 쓸모가 큽니다.

실제 사례 · SMARTSHOT 크롬 확장(캡처·OCR·주석), 위스퍼 기반 캡컷 자막 자동화, 줌 자동 녹화.

처음 시작한다면, 이 순서로

  1. 1번 → 2번 : 가장 빨리 눈에 보이는 결과가 나옵니다. 첫 성공 경험으로 좋습니다.
  2. 3번 → 5번 : "내 일이 줄어든다"를 바로 체감할 수 있습니다.
  3. 6번 → 7번 : 매번 반복하던 서류·증명서 작업을 맡겨 봅니다.
  4. 4번 → 8번 : 내 자료를 모아 "나만의 시스템"으로 키워 갑니다.
