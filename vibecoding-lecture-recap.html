Part 1

AI를 에이전트로 쓰는 법

💬 "채팅"과 "워크(Work)"는 다르다 — 크레딧이 여기서 갈린다

GPT·클로드 등에는 일반 대화창(Chat) 말고 Work / 에이전트 모드가 따로 있습니다. 둘의 차이를 모르고 쓰면 크레딧이 순식간에 사라집니다.

  • Chat (일반 대화) — 질문하고 답을 받는 것. 인포그래픽 만들기, PPT 만들기, 이미지 여러 장 생성 등 "결과물을 뚝딱 받는" 작업은 전부 여기서 충분합니다.
  • Work (에이전트) — 내가 직접 못 하는 걸 "대신 행동"하게 시키는 것. 예를 들어 이메일 자동 발송, 캘린더 확인 후 알림, 여러 사이트를 돌며 정보 수집처럼 "AI가 직접 뭔가를 하고 와야 하는" 작업만 여기로 보내면 됩니다.
핵심 원칙 최대한 그냥 Chat(기본 모드)에 시켜보고, "나 이거 못해"라는 답이 나올 때만 Work로 넘어가세요. 대부분의 작업은 Work가 전혀 필요 없습니다.

📸 오늘의 가장 중요한 팁 — "스크린샷을 잘해야 한다"

텍스트로 길게 설명하는 대신, 화면을 캡처해서 AI에게 그대로 보여주는 습관이 이 강의 전체를 관통하는 핵심입니다.

  • PC에서 — Window + Shift + S로 원하는 영역을 캡처한 뒤, 대화창에 Ctrl + V로 붙여넣기
  • 스마트폰에서 — 기기 기본 스크린샷 기능 사용 (전원+음량하 등 기기별 단축키)
  • 화살표나 표시를 추가해서 "이 부분만 바꿔줘"라고 하면 AI가 훨씬 정확하게 알아듣습니다.
  • 물건 고장이나 설정 오류처럼 말로 설명하기 애매한 상황도, 그냥 사진을 찍어서 보여주면 AI가 알아서 원인과 해결법을 찾아줍니다.
강의 중 실제 예시 전기자전거 타이어가 펑크났을 때, 바꿔 낀 타이어 밸브 사진 한 장만 찍어 보여주자 AI가 "이건 프레스타가 아니라 슈뢰더 방식"이라며 바로 필요한 펌프를 특정해줬습니다. 예전처럼 상황을 하나하나 설명할 필요가 없어진 겁니다.

🎨 바로 써먹는 명령어 모음

  • 인포그래픽 만들기 — "○○ 방법을 인포그래픽 10개로 만들어줘" (단어를 몰라도 "그림과 함께 설명해줘"라고만 해도 충분)
  • 여러 장 이미지 동시 생성 — "하나하나 따로따로 독립적인 이미지로 만들어줘"라고 명확히 요청하세요. 이때 추론 수준을 "높음" 이상으로 올려야 제대로 나옵니다.
  • PPT·자료 초안 — 대상(초등학생 대상, 시니어 대상 등)을 함께 말해주면 그 눈높이에 맞춰 만들어줍니다.
  • 내 얼굴·사진 활용 — 내 사진을 주면 포스터나 아바타에 그대로 반영됩니다. 옷을 갈아입히거나(쇼핑몰 옷 사진 첨부) 3D 아바타로 바꾸는 것도 가능합니다.
  • 홍보 포스터 — 그냥 "포스터 만들어줘"만 하면 정보가 빈약한 결과물이 나옵니다. 블로그 글이나 신청서 내용을 함께 읽혀야 실제로 쓸 수 있는 결과물이 나옵니다.

⏱ 여러 작업을 동시에 돌려라

이미지·PPT 생성처럼 시간이 걸리는 작업이 있을 때, 화면을 붙잡고 기다리지 마세요. 시켜놓은 채로 새 채팅을 열어 다른 작업을 진행하다가, 나중에 돌아와서 확인하면 됩니다. 박성욱 작가는 보통 한 번에 5~6개 작업을 동시에 돌립니다.

크레딧 관리 주의사항 (1부 종합)
  • 대화창(Chat)에서 할 수 있는 걸 Work에서 하면 같은 결과에 크레딧만 낭비됩니다.
  • 세션(대화)이 길어질수록 AI가 처음부터 전체를 다시 읽기 때문에 크레딧이 급격히 늘어납니다 — 목적이 바뀌면 새 채팅을 여세요.
  • 자동 충전(Auto Reload)은 반드시 꺼두세요. 실수로 충전돼도 환불이 안 됩니다.
Part 2

바이브 코딩 — 클로드 코드 / 코덱스

🖥 "웹"과 "데스크톱 앱"은 다른 공간이다

GPT·클로드를 브라우저(웹)에서 쓰는 것과, PC에 설치하는 클로드 코드 / 코덱스(데스크톱 앱)는 완전히 다릅니다. 데스크톱 앱은 내 PC의 프로그램을 직접 켜고 끄고, 파일을 만들고, 오류가 나면 스스로 재시작까지 합니다.

  • GPT → 데스크톱 앱은 코덱스(Codex) (GPT Plus 이상 필요)
  • 클로드 → 좌측 상단 "코드" 메뉴에서 PC 앱을 검색해 설치
  • 구글 → 안티그래비티(Antigravity) — 무료로도 어느 정도 사용 가능

💰 크레딧 세팅 — 시작 전에 반드시 확인

설정 → 사용량에서 자동 충전(Auto Reload) 끄기, 한도는 0으로 설정해두세요. 필요할 때만 다시 켜면 됩니다.

모델은 작업 난이도에 맞춰 고르면 됩니다.

하이쿠문서 정리·요약 등 단순 작업에 충분
소넷웹사이트 제작 등 일반적인 작업 대부분 — 기본으로 충분
오퍼스방대한 자료를 한 번에 이해시켜야 할 때
페이블가장 똑똑하지만 크레딧 소모가 큼 — 투자 분석처럼 정말 복잡한 작업에만

📁 "로컬 폴더" 개념 — 오늘 강의의 핵심

AI에게 내 PC의 작업 폴더를 통째로 열어주는 것이 웹 채팅과의 결정적인 차이입니다. 클로드 코드·코덱스에게 폴더를 지정해주면, 그 안의 모든 자료(과거 기획서·이미지·엑셀 등)를 스스로 참고해서 작업합니다.

  • 웹의 일반 대화(GPT·재미나이 등)는 내 PC 파일 경로에 접근하지 못합니다 — 파일을 매번 직접 첨부해서 줘야 합니다.
  • 코드(클로드 코드·코덱스)는 폴더 자체를 "보고" 있기 때문에 매번 파일을 올릴 필요가 없습니다.
강의 중 실습 예시 로고 이미지를 작업 폴더에 미리 넣어두기만 하면, "로고 넣어줘"라는 말만으로 AI가 QR코드 페이지에 알아서 그 로고를 찾아 삽입했습니다.

🌐 HTML·아티팩트로 결과물 만들기 → 배포까지

  • 클로드·코덱스에게 "아티팩트로 만들어줘" 또는 "시각화해줘"라고 하면 HTML 문서(사이트 형태)로 결과물을 만들어줍니다.
  • HTML로 만들어두면 클로드·GPT·재미나이 어디서든 다시 열고 수정할 수 있어 특정 서비스에 종속되지 않습니다. 클로드 구독을 끊으면 아티팩트는 사라지지만, 로컬에 HTML로 저장해두면 계속 내 것으로 남습니다.
  • 공유·배포는 별도 문제입니다 — "내 PC에서만 보이는 것"과 "누구나 볼 수 있게 배포하는 것"을 구분해야 합니다.
  • 랜딩페이지를 만들 때는 들어갈 이미지들을 미리 폴더에 넣어두고 통째로 참고시키면 훨씬 완성도 높은 결과물이 나옵니다.
배포 방법 박성욱 작가는 Vercel에 배포해서 실제 웹사이트로 공개합니다. 처음이라면 AI에게 "Vercel 가입하는 법 알려줘"라고 물어보는 것부터 시작하면 됩니다.

📝 MD 파일 → 옵시디언 연계

영상이나 자료를 AI에게 주고 "MD 파일로 요약해줘"라고 하면, 용량이 아주 가벼운 텍스트 요약 파일이 만들어집니다. 이렇게 쌓인 MD 파일들을 옵시디언(Obsidian) 같은 로컬 프로그램에 모아두면, 나중에 필요한 주제만 골라 다시 활용할 수 있습니다.

노션도 비슷한 기능을 하지만, 구독이 끊기면 자료도 함께 접근이 어려워집니다 — 로컬에 저장하는 것이 핵심입니다.

🎬 그 밖에 가능한 것들 (실습 없이 소개만)

  • 영수증 사진 여러 장을 한 번에 올려서 엑셀로 자동 정리
  • 영상 폴더를 지정해주면 말끊김 제거 + 자막 삽입 편집까지 자동 처리
  • 매일 자동으로 공지사항을 수집해 정리해주는 프로그램, 티스토리 자동 포스팅 등 "매일 반복되는 일"의 자동화

✅ 오늘 강의 한 줄 정리

  1. Chat과 Work(에이전트)를 구분해서 쓰면 크레딧을 대부분 아낄 수 있다.
  2. 스크린샷이 프롬프트보다 강력하다 — 말로 설명하지 말고 보여줘라.
  3. 프롬프트를 정교하게 짜는 시대는 지났다 — "내가 뭘 만들고 싶은지"만 명확하면 나머지는 AI가 알아서 한다.
  4. 바이브 코딩의 핵심은 내 PC 폴더를 통째로 맡기는 것 — 로컬 개념을 이해하면 완전히 달라진다.
  5. 결과물은 HTML로 로컬에 저장해야 특정 서비스 구독이 끊겨도 내 것으로 남는다.
  6. 세션(대화)이 길어질수록 크레딧이 급격히 는다 — 목적이 바뀌면 새로 시작하라.
