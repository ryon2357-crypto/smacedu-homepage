코덱스 지시문 카드 (그대로 복사해서 붙여 넣고, [ ] 안만 내 상황에 맞게 바꾸세요)

========================================
카드 0. 항상 맨 앞에 붙이는 안전 문장
========================================
원본 파일은 절대 수정하거나 삭제하지 말고, 반드시 복사본(또는 새 폴더)에서만 작업해 줘.
파일을 읽고 조사하는 것은 바로 해도 되지만, 파일을 옮기거나 이름을 바꾸는 작업은 먼저 계획을 보여 주고 내가 '진행'이라고 하면 그때 실행해 줘.

========================================
카드 1. 폴더 점검 (읽기만)
========================================
이 폴더에 있는 파일을 전부 살펴보고, 어떤 종류의 파일이 몇 개씩 있는지 표로 알려 줘.
파일 이름과 실제 내용이 다른 것, 똑같은 내용의 중복 파일, 업무와 관련 없어 보이는 파일도 따로 찾아 줘.
아직 아무것도 바꾸지 마.

========================================
카드 2. 정리 계획 세우기
========================================
방금 점검한 결과로 정리 계획을 세워 줘.
- 폴더는 [영수증 / 강의계획서 / 수강신청서 / 회의록 / 견적서 / 행사사진 / 안내문 / 확인필요] 로 나눠 줘.
- 파일 이름은 [날짜_종류_내용] 형식으로 바꿔 줘.
- 어떤 파일이 어디로 가고 이름이 어떻게 바뀌는지 표로 먼저 보여 줘.

========================================
카드 3. 실행과 검수
========================================
진행해 줘. 끝나면 정리 전과 후의 파일 개수를 비교해서 빠진 파일이 없는지 확인해 줘.
그리고 정리된 전체 목록을 엑셀 파일로 저장해 줘.

========================================
카드 4. 홈페이지 만들기
========================================
[이 폴더의 1~4번 텍스트와 사진 3장]을 사용해서 강사 소개 홈페이지를 만들어 줘.
- 한 페이지, 카드 모양의 강좌 소개, 후기, 문의 방법, 신청 버튼
- 따뜻하고 밝은 분위기, 글자는 크게
- 휴대폰 화면에서도 글자가 잘리지 않게
다 만들면 직접 열어서 확인하고, 문제가 있으면 스스로 고친 뒤 무엇을 고쳤는지 알려 줘.

========================================
카드 5. 홈페이지 수정 요청 예시
========================================
- 제목 글자를 더 크게 하고 배경을 연한 노란색으로 바꿔 줘.
- 신청 버튼을 화면 맨 아래에도 하나 더 추가해 줘.
- 휴대폰 화면에서 보면 어떻게 보이는지 확인하고 어색한 곳을 고쳐 줘.

========================================
카드 6. 신청서 접수 확인 자동화
========================================
'가상_신청서_접수현황.xlsx'를 '접수확인_기준.txt'의 기준대로 점검해 줘.
- 문제 없는 건과 확인이 필요한 건을 나눠서 새 엑셀 파일로 저장
- 확인이 필요한 건은 어떤 문제인지 이유를 한 칸에 적기
- 마지막에 한 장짜리 요약 보고서(총 접수, 정상, 확인 필요, 정원 현황)를 만들어 줘
- 원본 파일은 수정하지 마

========================================
카드 7. 내 업무로 바꾸는 법 (숙제)
========================================
[내가 매주 반복하는 일] 을 하려고 해. 어떤 자료가 필요하고, 어떤 순서로 하면 되는지 먼저 질문해 줘.
그 다음 위의 '무엇을 / 어떤 자료로 / 꼭 들어갈 것 / 완성 기준' 네 가지를 정리해서 보여 줘.
