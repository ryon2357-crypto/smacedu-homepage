COPY & PRACTICE

실습 프롬프트
복사해서 쓰기

원하는 카드의 ‘복사하기’를 누른 뒤 코덱스 입력창에 붙여 넣으세요. 대괄호 안의 내용만 내 자료와 목적에 맞게 바꾸면 됩니다.

사용 순서카드 0 안전 문장을 먼저 붙이고, 실습 단계에 맞는 카드를 이어서 붙여 넣으세요. 실제 자료는 복사본 폴더에서 연습하는 것이 안전합니다.
CARD 0 · SAFETY

항상 맨 앞에 붙이는 안전 문장

원본 파일은 절대 수정하거나 삭제하지 말고, 반드시 복사본(또는 새 폴더)에서만 작업해 줘.
파일을 읽고 조사하는 것은 바로 해도 되지만, 파일을 옮기거나 이름을 바꾸는 작업은 먼저 계획을 보여 주고 내가 '진행'이라고 하면 그때 실행해 줘.
CARD 1 · CHECK

폴더 점검

이 폴더에 있는 파일을 전부 살펴보고, 어떤 종류의 파일이 몇 개씩 있는지 표로 알려 줘.
파일 이름과 실제 내용이 다른 것, 똑같은 내용의 중복 파일, 업무와 관련 없어 보이는 파일도 따로 찾아 줘.
아직 아무것도 바꾸지 마.
CARD 2 · ORGANIZE

폴더 정리·검수·목록 만들기

폴더는 영수증 / 강의계획서 / 수강신청서 / 회의록 / 견적서 / 행사사진 / 안내문 / 확인필요로 나눠 줘.
파일 이름은 날짜_종류_내용 형식으로 바꿔 줘.
끝나면 정리 전과 후의 파일 개수를 비교해서 빠진 파일이 없는지 확인해 줘.
정리된 전체 목록을 엑셀 파일로 저장해 줘.
영수증은 중복과 견적서를 제외하고 합계 금액도 계산해 줘.
CARD 3 · TEMPLATE

중요한 MD 파일로 지정하기

현재 템플릿을 이 폴더의 중요한 md 파일로 지정해줘. 이름도 그렇게 만들어줘.
CARD 4 · WORKSPACE

작업 폴더 구조 만들기

지금 열려 있는 작업 폴더 안에 다음 세 폴더를 만들어 줘.

input: 원본 자료 보관
work: 복사본으로 실제 작업
output: 완성된 결과물 저장

같은 이름의 폴더가 이미 있으면 그대로 두고, 없는 폴더만 새로 만들어 줘.

기존 파일은 옮기거나 수정하거나 삭제하지 마.
완료되면 세 폴더의 위치를 확인해서 알려 줘.
CARD 5 · WEBSITE

반응형 홈페이지 만들기

이 내용을 기반으로 반응형 홈페이지 만들어줘.
CARD 6 · KAKAO

카카오톡 창 정렬 단축키 만들기

카카오톡 창이 너무 많이 열리면 정신이 없어. 단축키로 카카오톡 창을 한쪽에 정렬하도록 만들어줘.
CARD 7 · AUTOMATION

신청서 접수 확인 자동화

가상_신청서_접수현황.xlsx를 접수확인_기준.txt의 기준대로 점검해 줘.

문제 없는 건과 확인이 필요한 건을 나눠서 새 엑셀 파일로 저장해 줘.
확인이 필요한 건은 이유를 한 칸에 적어 줘.
마지막에 한 장짜리 요약 보고서도 만들어 줘.

총 접수, 정상, 확인 필요, 강좌별 정원 현황을 넣고 원본은 수정하지 마.
CARD 8 · VIDEO

짧은 영상 모아 편집하기

영상 편집을 하고 싶어. 짧은 영상들을 모아서 한편의 영상으로 만들어줘. 중간에 무음 구간이나 필요 없는 구간은 컷편집해. 자막은 가독성 좋게 넣어서 만들어줘.
CARD 9 · FFMPEG

FFmpeg 설치하기

ffmpeg를 다운로드해서 영상 편집할 수 있게 해줘
