# 📥 inbox — 원본 자료를 여기에 넣습니다

클라우드 세션의 Claude는 아래에 **접근할 수 없습니다**:

- 로컬/네트워크 드라이브 (`W:\...`, `file:///...`)
- 네이버 (`cafe.naver.com`, `blog.naver.com`) — 네트워크 정책 차단
- 로그인이 필요한 페이지

그래서 자료는 **사람이 여기로 옮겨줘야** 합니다.

---

## 넣는 방법

**로컬 PC(Claude Desktop / VS Code)에서 작업 중이라면** — 가장 쉬움:
```
파일을 brand/inbox/ 에 복사 → 커밋 → 푸시
```

**웹·모바일에서 작업 중이라면**:
- 글: 본문을 복사해서 `.md` 파일로 저장하거나 대화창에 붙여넣기
- 화면: 스크린샷을 이미지로 저장

---

## 파일 이름 규칙

```
YYYYMMDD_출처_주제.확장자

예)
20260904_여사탐카페_운영전략분석.html
20260903_네이버카페woosra_49953_원문.md
20260903_경쟁사랜딩_스크린샷.png
```

---

## 처리되면

Claude가 분석해서 `brand/sources/` 에 **"우리가 가져갈 것"** 으로 정리하고,
반복 확인된 패턴은 `voice.md` / `design.md` / `strategy.md` 로 승격시킵니다.

분석이 끝난 원본은 여기 남겨둬도 되고, 용량이 크면 지워도 됩니다
(중요한 건 `sources/` 에 남은 해석이지 원본이 아닙니다).
