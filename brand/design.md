# 디자인 언어

> 상태: 🟡 **초안** — 운영 중인 랜딩페이지의 CSS에서 실제 토큰을 추출한 것.

---

## 기본 방향

**다크 테마 기반.** 사진·영상 강의가 주력이라, 작품 이미지가 배경에 묻히지 않고 떠 보이게 하는 것이 목적.
배경은 완전한 검정이 아니라 **약간 색이 도는 어두운 회색**을 씁니다.

---

## 색 토큰

실제 사용 중인 값 (페이지마다 강조색만 갈아끼우는 구조):

```css
/* 공통 골격 */
--bg:      #0f0f0f;                        /* 사진 계열 */
--bg:      #120a14;                        /* 바이브코딩 계열 (보라 기운) */
--text:    #e8e8e8;                        /* 본문 — 순백(#fff) 아님. 눈부심 방지 */
--muted:   #888;                           /* 보조 설명 */
--border:  rgba(255,255,255,0.08);         /* 아주 옅은 구분선 */
--radius:  14px;
```

```css
/* 강조색 — 주제별로 교체 */
/* 사진/따뜻함 계열 */
--grad:      linear-gradient(135deg, #f59e0b, #ef4444);   /* 버튼·배지 */
--grad-text: linear-gradient(135deg, #fbbf24, #fb7185);   /* 그라데이션 글자 */

/* AI·코딩/차가움 계열 */
--grad:      linear-gradient(135deg, #ec4899, #8b5cf6);
--grad-text: linear-gradient(135deg, #f9a8d4, #c4b5fd);
```

### 규칙

1. **새 페이지를 만들 때 골격(`--bg`/`--text`/`--muted`/`--border`/`--radius`)은 그대로 두고
   `--grad` 와 `--grad-text` 두 개만 주제에 맞게 바꿉니다.** 이게 시리즈처럼 보이는 이유입니다.
2. 그라데이션 각도는 **항상 `135deg`**. 섞지 않습니다.
3. 본문 텍스트에 순백(`#ffffff`)을 쓰지 않습니다. 어두운 배경에서 눈이 아픕니다.
4. 테두리는 선이 아니라 **거의 안 보이는 경계**(alpha 0.08)로 처리합니다.

## 레이아웃

- 섹션마다 `<h2>` 하나 + 내용. 한 섹션은 **한 가지 메시지**만 담습니다.
- 스크롤 진입 애니메이션: `.reveal` 클래스로 페이드인.
  - ⚠️ 스크린샷 검증할 때 이것 때문에 요소가 안 찍힘.
    테스트 사본에 `.reveal{opacity:1!important}` 를 임시로 넣고 확인 후 삭제.
- CTA 버튼은 **히어로(상단)와 하단 두 곳에** 배치. 그 아래 `🎁 신청만 해도 ~` 문구를 반복.

## 이미지 규칙

### Open Graph 배너 (필수)
- 규격 **1200 × 630**
- 없으면 카카오톡이 페이지 안의 아무 이미지(주로 강사 사진)를 끌어다 씁니다.
- 제작: 디자인 HTML을 만들고 헤드리스 Chrome 스크린샷
  `chrome --headless --window-size=1200,630 --screenshot=...`
- 카카오 캐시 때문에 배포 직후 확인 시 URL 뒤에 `?v=2` 를 붙여 공유.

### 날짜·시간 배지는 반드시 이미지로
모바일 브라우저(삼성 인터넷·카톡 인앱)가 날짜 텍스트를 가로채서 제멋대로 칩 박스를 씌웁니다.
`format-detection` 메타태그도, zero-width space 삽입도 통하지 않았습니다.
**짧은 배지·헤드라인의 날짜는 PNG로 만들어 `<img>` 로 넣습니다** (`alt` 필수).
긴 본문에는 적용하지 않습니다.
