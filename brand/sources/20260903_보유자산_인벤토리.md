## 1. 「브랜딩, 브랜드 디파인」 ⭐ 가장 중요

- 위치: Google Docs · 2026-05-16 작성
- [문서 열기](https://docs.google.com/document/d/1IT1JDVFy11Iv5aLh5Yf2Ce6FjPad2-sS6ydBrRXtNdA/edit)

우리가 쓸 수 있는 **완성된 브랜딩 프레임워크**가 이미 여기 있다.

### 브랜드 핵심 문장 공식
```
나는 [누구를] + [어떤 문제를] 해결해서 + [어떤 결과를] + [어떤 방식으로] 돕습니다.
```

### 고객 문제의 3단계 구조 — 카피 쓸 때 그대로 씀
| 단계 | 내용 | 어디에 쓰나 |
|---|---|---|
| 외적 문제 | 겉으로 드러나는 현실적 불만 | **콘텐츠 제목** |
| 내적 문제 | 불안, 두려움 등 감정 | **공감 카피** |
| 철학적 문제 | 이 문제를 보는 나의 신념 | **브랜드 방향성** |

### 에피파니 스토리 5단계
① 예전의 나 → ② 전환점 → ③ 새로운 방법 → ④ 결과 → ⑤ 약속

원칙: **고객이 주인공, 나는 조력자(셸파).** 극적인 성공보다 작은 깨달음이 더 공감된다.

### 경험 자산 발굴 5필터
해왔던 일 / 자주 받는 질문 / 나만의 효율 / 깊은 공감 / 돈 받을 수 있는 경험

> ✅ **이 프레임워크를 `brand/strategy.md` 로 승격 완료.**

## 2. 「엘란비탈 브랜딩」

- [문서 열기](https://docs.google.com/document/d/1_SKbJ9OUMxfkgceyXdWN21KubSWQu031lIxPUWzZ6Lk/edit)

### 가격 사다리 (다른 업종 사례를 우리 식으로 메모해둔 것)
```
무료 → 5만원 특강 → 660만원 컨설팅 → 5,000만원 실행
```
각 단계의 전환 논리가 핵심:
- 5만원 특강 후 → "5만원 냈는데 이 정도로 알려준다고?"
- 희망은 얻었지만 → "혼자서는 못하겠는데"
- 660만원 컨설팅 후 → "알수록 더 무섭다, 그냥 해주면 안 돼요?"
- **비싼 가격을 싸게 보이게 만드는 법**: 직접 해봤을 때의 실제 비용(보증금·설비·시행착오)을 알려주면 됨

### 신뢰 자산 (실재하는 것)
서울대 / 사진전문가 / 어도비 / 니콘 / 싱가포르 AI / 엘란비탈(주) + 협회

> 메모: "돈으로 인맥은 못 사지만, 홈페이지로는 인맥을 살 수 있다."

## 4. 실제 유입 경로 데이터 ⭐ 추측이 아닌 실측

- 출처: [0227 사진특강 신청서(응답)](https://docs.google.com/spreadsheets/d/194pbBT6kAa1VZKxUNJOnGAfXReNCaVPNR67vDAbZ40s/edit)

신청자가 직접 답한 "신청 경로" (표본 일부 기준 순위):

| 순위 | 경로 | 비중 |
|---|---|---|
| 1 | **오픈톡방** | 압도적 1위 |
| 2 | 메일 (기존 DB) | 2위 |
| 3 | SNS 광고 | 3위 |
| 4 | 사진카페 (포랩/포토피플) | 소수 |
| 5 | 네이버 블로그 / 블로그 이웃 | 소수 |
| 6 | 지인 추천 | 소수 |

### 여기서 읽어야 할 것
- **모객의 주력은 광고가 아니라 커뮤니티(오픈톡방)와 자체 DB(메일)다.**
  → 신규 유입보다 **보유 관계의 재활성화**가 실제 엔진.
  → `strategy.md` 의 "커뮤니티 귀속" 레버가 데이터로 확인됨.
- 카페·블로그 비중이 낮음 → 지금 여사탐 카페 같은 커뮤니티 운영 전략을
  학습하려는 방향은 **약한 채널을 보강**하는 시도로 타당.

⚠️ **검증 필요**: 위 순위는 시트 일부만 본 것. 전체 집계로 다시 확인할 것.

## 5. 고객이 스스로 말한 니즈 (같은 시트, "배우고 싶은 것" 응답)

원문 그대로 자주 나온 표현 — **이게 곧 카피의 재료**:

> "과도하지 않고 자연스러운 보정" · "같은 사진이라도 달라 보이는 사진"
> "일상생활에서 사진을 잘 찍고 싶어요" · "100층 건물을 자르지 않고 앞의 인물 담는 법"
> "음식 사진 잘 찍는 법" · "사진 잘 찍어서 유튜브 업로드 하고 싶어요"

### 읽어야 할 것
- 고객은 **"사진 기술"** 이 아니라 **"내 일상이 달라 보이는 것"** 을 원한다.
- 요청이 극도로 **구체적**이다 ("100층 건물을 자르지 않고"). 추상적 카피가 안 먹히는 이유.
- 목적이 촬영에서 끝나지 않고 **업로드·공유**까지 간다 (유튜브, SNS).
  → 강의 결과물을 "찍는 법"이 아니라 "올릴 수 있는 것"으로 포장해야 함.

> ✅ 이 표현들을 `voice.md` 의 카피 재료로 승격 완료.
