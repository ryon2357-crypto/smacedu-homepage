# 1단계 — 규모 파악 (카페 메인에서 바로 보임)

| 항목 | 값 | 어디서 보나 |
|---|---|---|
| 전체 회원수 | | 카페 메인 좌측 |
| 카페 개설일 | | 카페 정보 |
| 즐겨찾기 수 | | 카페 정보 |
| 일 방문자 수 | | 카페 메인 (공개 시) |
| 카페 등급 | | 씨앗/새싹/잎새/가지/나무/열매/숲 |
| 전체 게시글 수 | | 카페 정보 |

**해석 기준**
- 회원수보다 **일 방문자 / 회원수 비율**이 중요. 3% 넘으면 살아있는 카페.
- 개설일 대비 회원수 → 성장 속도. 최근 급성장이면 지금 통하는 전략이 있다는 뜻.

# 2단계 — 수익 구조 해부 (게시판 목록만 봐도 드러남)

게시판 이름을 쭉 훑으면 돈 버는 경로가 보인다. 해당되는 것에 체크:

- [ ] **유료 강의 / 정규 과정** (기수제) → 주력일 가능성 높음
- [ ] **출사 / 워크샵** (참가비)
- [ ] **공동구매 / 장비 판매** (수수료)
- [ ] **카페 배너 광고 / 제휴사**
- [ ] **협찬 리뷰** (카메라·렌즈 브랜드)
- [ ] **인쇄/액자/앨범 등 제작 서비스**
- [ ] **등업 조건** (활동 강제 → 모수 유지 장치)
- [ ] **유료 회원 등급 / 멤버십**

### 각 상품별로 채울 표

| 상품명 | 단가 | 연 회차 | 회당 정원 | 예상 충원율 | 연 매출 |
|---|---|---|---|---|---|
| 예) 정규 사진반 | 400,000 | 4 | 20 | 80% | 25,600,000 |
| | | | | | |
| | | | | | |
| | | | | | |
| **합계** | | | | | |

> **연 매출 = 단가 × 연 회차 × 정원 × 충원율**
>
> 충원율을 모를 때 추정법: 모집 글의 **댓글 수 / 정원**.
> 네이버 카페 강의 모집은 보통 댓글로 신청받으므로 댓글 수가 거의 실제 신청자 수.

# 3단계 — 실제 판매량 역산 (추측 금지, 흔적으로 계산)

카페에는 매출 흔적이 남는다. 이걸 세면 된다:

| 단서 | 세는 법 | 알 수 있는 것 |
|---|---|---|
| 모집글 댓글 수 | 최근 3개 기수 평균 | 회당 실제 신청자 |
| 후기 게시판 글 수 | 기수별 후기 개수 | 실제 수강 완료자 (보통 수강생의 30~50%가 후기 작성) |
| 모집글 조회수 | 조회수 ÷ 신청자 | 전환율 |
| 모집 주기 | 최근 1년 모집글 날짜 간격 | 연 회차 |
| 정원 마감 속도 | "마감" 댓글까지 걸린 시간 | 수요 강도 |

**후기로 역산하는 법**
```
실제 수강생 ≈ 후기 글 수 ÷ 0.4   (후기 작성률 40% 가정)
```
