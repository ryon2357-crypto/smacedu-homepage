# 📚 sources — 외부 자료 분석 결과

`inbox/` 의 원본을 읽고 **"우리가 가져갈 것"만** 남긴 곳입니다.
원문 복사본이 아닙니다. 원문은 여기 오면 안 됩니다.

---

## 작성 템플릿

파일명: `YYYYMMDD_대상.md` (예: `20260904_여사탐카페.md`)

```markdown
# [대상 이름]

- **출처**: URL 또는 파일명
- **분석일**: YYYY-MM-DD
- **왜 봤나**: 무엇이 궁금해서 이 자료를 봤는지

## 관찰 — 무엇을 하고 있나
(사실만. 판단 섞지 않기)

## 왜 통하는가 — 작동 원리
(관찰을 메커니즘으로 설명)

## 우리에게 옮길 것
| 가져올 것 | 우리 맥락에서의 형태 | 반영할 문서 |
|---|---|---|
| | | |

## 옮기지 않을 것
(그리고 그 이유 — 이게 브랜드 정체성을 지킵니다)

## 검증 필요
(추측인 부분을 명시. 나중에 확인)
```

---

## 규칙

1. **관찰과 해석을 분리합니다.** "무엇을 하는가"와 "왜 통하는가"를 섞지 않습니다.
2. **안 가져올 것도 씁니다.** 무엇을 거절했는지가 브랜드를 만듭니다.
3. 여러 자료에서 **반복 확인된 패턴만** `voice.md` / `design.md` / `strategy.md` 로 승격합니다.
   한 번 본 것은 여기 머무릅니다.
