## 작업 흐름

```
외부 자료 (네이버 카페, 로컬 파일, 스크린샷, 경쟁사 페이지)
        ↓  사용자가 넣음
   brand/inbox/          ← 원본 그대로
        ↓  Claude가 분석
   brand/sources/        ← "무엇을 배웠나" 정리
        ↓  규칙으로 승격
 voice.md / design.md / strategy.md   ← 다음 작업의 기준
        ↓
   실제 페이지·카피 제작
        ↓
   brand/LOG.md 에 기록 + 커밋 + 푸시
```

**핵심 규칙: 원문 복붙 금지.** `sources/` 에는 "이 자료에서 우리가 가져갈 것"만 씁니다.
그리고 반복해서 확인된 패턴만 `voice.md` / `design.md` / `strategy.md` 로 승격시킵니다.
