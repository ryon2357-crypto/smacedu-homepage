## 우리가 파는 것

## 퍼널 구조 (현재 작동 중인 형태)

```
무료 특강 랜딩  →  신청(이름·연락처·이메일)  →  확인 메일 + 선물 PDF + 카톡방
      ↓                                                   ↓
 "신청만 해도 선물"                              커뮤니티 안에서 관계 유지
      ↓                                                   ↓
   실제 참석  →  후기 요청(review-gift)  →  VIP 1:1 / 유료 과정 / 자격증
```

**핵심 레버 3개:**
1. **무료 진입** — 결제 장벽 없이 연락처를 얻는다
2. **즉시 보상** — 신청 즉시 손에 뭔가 쥐어준다 (참석 여부와 무관하게 관계 시작)
3. **커뮤니티 귀속** — 카톡방으로 넣어 일회성 접점을 지속 접점으로 바꾼다

## 실제 유입 경로 (추측 아님 — 신청서 응답 실측)

신청자가 직접 답한 "신청 경로" 순위:

| 순위 | 경로 |
|---|---|
| 1 | **오픈톡방** (압도적) |
| 2 | 메일 (기존 DB) |
| 3 | SNS 광고 |
| 4 | 사진카페 (포랩/포토피플) |
| 5 | 네이버 블로그 |
| 6 | 지인 추천 |

**읽어야 할 것: 우리 모객 엔진은 광고가 아니라 "이미 관계를 맺은 사람들"이다.**
오픈톡방 + 메일 DB가 1·2위. 신규 획득보다 **보유 관계의 재활성화**가 실제로 매출을 만든다.
→ 그래서 "즉시 보상 → 카톡방 귀속"이 단순 서비스가 아니라 **핵심 자산 축적 활동**이다.

카페·블로그 비중이 낮은 것은 약점. 커뮤니티 운영 전략을 학습하려는 방향은 타당하다.

⚠️ 위 순위는 시트 일부 표본. 전체 집계로 재확인 필요.

## 고객이 실제로 쓴 말

신청서의 "배우고 싶은 것" 응답 원문:

> "과도하지 않고 자연스러운 보정" · "같은 사진이라도 달라 보이는 사진"
> "100층 건물을 자르지 않고 앞의 인물 담는 법" · "사진 잘 찍어서 유튜브 업로드 하고 싶어요"

**세 가지가 보인다:**
1. 고객이 원하는 건 "사진 기술"이 아니라 **"내 일상이 달라 보이는 것"**
2. 요청이 극도로 **구체적**이다 → 추상적 카피가 안 먹히는 이유
3. 목적이 촬영에서 안 끝나고 **올리는 것(유튜브·SNS)** 까지 간다
   → 강의 결과를 "찍는 법"이 아니라 **"올릴 수 있는 것"** 으로 포장해야 함

## 브랜드 핵심 문장

우리가 이미 가진 프레임워크 (출처: 「브랜딩, 브랜드 디파인」):

```
나는 [누구를] + [어떤 문제를] 해결해서 + [어떤 결과를] + [어떤 방식으로] 돕습니다.
```

### 고객 문제의 3단계 — 카피 쓸 때 그대로 씀

| 단계 | 내용 | 어디에 쓰나 |
|---|---|---|
| 외적 문제 | 겉으로 드러나는 불만 | **콘텐츠 제목** |
| 내적 문제 | 불안·두려움 | **공감 카피** |
| 철학적 문제 | 이 문제를 보는 신념 | **브랜드 방향성** |

타깃은 뾰족할수록 좋다. "시니어"가 아니라 "AI 강의를 시작하고 싶은 40대 전문가"처럼.

### 에피파니 스토리 5단계
① 예전의 나 → ② 전환점 → ③ 새로운 방법 → ④ 결과 → ⑤ 약속

**고객이 주인공, 우리는 조력자(셸파).** 극적인 성공보다 작은 깨달음이 더 공감된다.

> ⬜ **미완성 과제**: 위 공식에 엘란비탈을 실제로 대입한 한 문장이 아직 없다.
> 이게 없으면 모든 랜딩페이지가 매번 다른 말을 하게 된다. **최우선 과제.**

## 차별화를 뽑는 법

「퍼스널브랜딩 2강」의 실전 질문:

> **"동네 아저씨가 하지 않는 것이 무엇인가?"**

경쟁자가 안 하는 것 — SNS 안 함 / 불친절 / 밤늦게 안 함 / 자격증 없음 / A/S 부실.
이걸 뒤집어 **"제가 무조건 해드리는 5가지 / 제가 하지 않는 5가지"** 로 제시한다.

현재 우리가 명확히 가진 것:
- **하나의 강사·하나의 톤**으로 사진 → AI → 코딩까지 이어지는 학습 경로
  (경쟁자는 대개 한 분야만)
- 신뢰 자산: 서울대 / 어도비 / 니콘 / 엘란비탈(주) + 협회
- 무료 특강의 완성도가 유료 수준

## 가격 사다리

「엘란비탈 브랜딩」에 정리된 전환 논리:

```
무료  →  5만원 특강  →  660만원 컨설팅  →  5,000만원 실행
```

각 단계가 다음 단계를 부르는 이유:
- 5만원 듣고 → *"5만원 냈는데 이 정도로 알려준다고?"* (기대 초과)
- 희망은 얻었는데 → *"혼자서는 못하겠는데"* (자각된 무력감)
- 660만원 듣고 → *"알수록 더 무섭다, 그냥 해주면 안 돼요?"* (위임 욕구)

**비싼 가격을 싸게 보이게 하는 법**: 직접 했을 때의 실제 비용(보증금·설비·시행착오)을 계산해서 보여준다.

우리 맥락 적용은 아직 미완 — 현재는 `무료 특강 → VIP 1:1 / 정규과정 / 자격증` 까지만 있음.
