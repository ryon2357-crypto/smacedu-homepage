## 우리가 파는 것

강의 자체가 아니라 **"나도 할 수 있게 됐다"는 상태 변화**입니다.
그래서 모든 페이지의 마지막은 커리큘럼이 아니라 `특강이 끝나면 이런 게 남아요` 로 닫힙니다.

## 퍼널 구조 (현재 작동 중인 형태)

```
무료 특강 랜딩  →  신청(이름·연락처·이메일)  →  확인 메일 + 선물 PDF + 카톡방
      ↓                                                   ↓
 "신청만 해도 선물"                              커뮤니티 안에서 관계 유지
      ↓                                                   ↓
   실제 참석  →  후기 요청(review-gift)  →  VIP 1:1 / 유료 과정 / 자격증
```

**핵심 레버 3개:**
1. **무료 진입** — 결제 장벽 없이 연락처를 얻는다
2. **즉시 보상** — 신청 즉시 손에 뭔가 쥐어준다 (참석 여부와 무관하게 관계 시작)
3. **커뮤니티 귀속** — 카톡방으로 넣어 일회성 접점을 지속 접점으로 바꾼다

## 전환 전략 체크리스트

랜딩페이지 만들 때 아래를 의식적으로 배치합니다.
(원본: [`documents/landing_page_10_core_strategies.md`](../documents/landing_page_10_core_strategies.md))

- [ ] **공감 스토리** — 같은 고민을 해봤다는 걸 먼저 보여주기
- [ ] **걱정거리 제시** — 인지 못 한 불안을 질문형으로 (`이런 고민, 해보셨죠?`)
- [ ] **마감형 이벤트** — 선착순/기간 한정
- [ ] **핵심장점 반복** — 상·중·하단 2~3회
- [ ] **숫자** — `2시간`, `3초` 같은 구체 수치
- [ ] **비교** — 하기 전 vs 한 후
- [ ] **신뢰 근거** — 협찬사, 자격증, 실제 이력
- [ ] **후기** — 이름·직업 포함, 상·중·하단 분산
- [ ] **동영상/GIF** — 2~3초 핵심 장면으로 스크롤 중단
- [ ] **참석 불가자 대안** — 이탈자를 리스트에서 잃지 않기

## 차별점 (다듬는 중)

현재 명확한 것:
- **하나의 강사·하나의 톤**으로 사진 → AI → 코딩까지 이어지는 학습 경로가 있음
  (대부분의 경쟁자는 한 분야만 다룸)
- 무료 특강의 완성도가 유료 수준 — 진입 장벽을 낮추되 품질로 신뢰를 삼

아직 검증 필요:
- [ ] 실제 수강생이 우리를 선택한 이유 (후기 데이터에서 추출)
- [ ] 경쟁 강의 대비 우리만의 한 문장 (아직 없음 — 만들어야 함)
